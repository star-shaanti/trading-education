# Guide pour obtenir un numéro D-U-N-S

## Qu'est-ce qu'un D-U-N-S ?

Un **D-U-N-S** (Data Universal Numbering System) est un identifiant unique à **9 chiffres** attribué gratuitement par **Dun & Bradstreet (D&B)** pour identifier les entreprises de manière unique dans le monde entier.

## Pourquoi en avez-vous besoin ?

**Pour Google Play Store :** Le D-U-N-S n'est généralement **PAS requis** pour les comptes développeurs individuels, MAIS peut être nécessaire pour :

- ✅ Les comptes d'organisation/entreprise
- ✅ Les applications **Finance** ou **Trading**
- ✅ Les applications qui nécessitent une vérification renforcée
- ✅ Certaines catégories spécifiques d'applications

**Note :** Pour une application de trading/éducation financière, avoir un D-U-N-S peut faciliter la vérification et la publication sur Google Play.

## Comment obtenir un D-U-N-S ?

### Option 1 : Demande gratuite (30 jours)

1. **Visitez le site officiel de D&B :**
   - Ouvrir : https://www.dnb.com/duns-number.html

2. **Choisissez l'option gratuite**
   - Sur la page, sélectionnez l'option de demande gratuite
   - Lisez attentivement les conditions

3. **Remplissez les informations de votre entreprise :**
   - Nom de l'entreprise
   - Adresse complète
   - Informations sur le dirigeant
   - Type d'activité
   - Nombre d'employés
   - Autres informations demandées

4. **Soumettez la demande**
   - Vérifiez toutes les informations avant de soumettre
   - Attendez la confirmation par email

5. **Délai :**
   - **Gratuit :** ~30 jours ouvrables
   - Le numéro D-U-N-S vous sera envoyé par email une fois la vérification terminée

### Option 2 : Demande accélérée (1-5 jours)

Si vous avez besoin du numéro plus rapidement :

1. Visitez le même site : https://www.dnb.com/duns-number.html
2. Choisissez l'option de traitement accéléré (payant)
3. Suivez le même processus de demande
4. Délai : **1 à 5 jours ouvrables**

**Coût :** Variable selon les options choisies (consultez le site pour les tarifs actuels)

## Informations à préparer avant la demande

- 📋 Nom légal de l'entreprise
- 📋 Adresse physique complète (pas une boîte postale)
- 📋 Numéro de téléphone professionnel
- 📋 Adresse email professionnelle
- 📋 Informations sur le dirigeant principal
- 📋 Type d'activité (code NACE/SIC si applicable)
- 📋 Date de création de l'entreprise
- 📋 Nombre approximatif d'employés

## Après réception du D-U-N-S

1. **Conservez-le en sécurité** : C'est un identifiant unique et permanent
2. **Utilisez-le pour Google Play Console** si demandé lors de la vérification
3. **Vous pouvez le vérifier** sur le site D&B à tout moment

## Liens utiles

- Demande de D-U-N-S : https://www.dnb.com/duns-number.html
- Vérifier un D-U-N-S existant : https://www.dnb.com/duns-lookup.html

## Notes importantes

⚠️ **Le D-U-N-S n'est pas toujours requis** pour Google Play, mais peut être demandé pour certaines catégories d'applications ou comptes d'entreprise.

⚠️ Le processus de vérification par D&B peut inclure un appel téléphonique pour confirmer les informations.

⚠️ Assurez-vous que toutes les informations fournies sont **exactes et cohérentes** avec vos documents officiels.

---

**Bon à savoir :** Si vous développez une application PWA (Progressive Web App) et envisagez de la convertir en APK via TWA (Trusted Web Activity) ou Capacitor, le D-U-N-S peut être particulièrement utile pour le processus de vérification Google Play.
